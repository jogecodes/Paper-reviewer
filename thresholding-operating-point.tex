Estimating score statistics or tail parameters therefore does not by itself select the intended alarm behavior: multipliers, percentiles, and risk levels still define the operating point. These choices can reflect operational requirements or heuristics without using anomaly labels. If they are selected by optimizing performance on labeled validation anomalies, however, supervision re-enters at the decision stage. A separate validation set avoids direct optimization on the test labels, but the calibration still depends on known anomalies.
