Simple statistical rules set thresholds a specified number of standard deviations above the score mean, or use robust alternatives based on the median absolute deviation or interquartile range \cite{outlier_thresholding}. These rules require a multiplier that determines how far a score must depart from the reference location or range to be labeled anomalous. Empirical-quantile rules instead use a selected percentile of the score distribution \cite{ruff_review_2021}. Both constructions leave an operating parameter to be specified. They can be applied without anomaly labels, but using an unlabeled sample potentially containing outliers differs from calibrating on a sample assumed to be entirely normal.
