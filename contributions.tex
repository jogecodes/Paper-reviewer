This paper introduces \textsc{AutoCUSUM}, a second-stage decision layer that converts an anomaly score stream into binary anomaly labels. It uses a CUSUM chart equipped with an automatic procedure for calibrating its reference value and decision limit. Using a finite sample of normal scores, the procedure optimizes a trade-off between sensitivity proxies and false-alarm penalties, without anomaly labels or a user-specified target alarm rate. We evaluate the method across different scoring models and datasets, comparing it with alternative decision rules using observation-level detection metrics, false-alarm episode counts, and detection delay.
