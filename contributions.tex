This paper introduces \textsc{AutoCUSUM} as a second-stage decision layer that converts an anomaly score stream into binary anomaly labels. It automatically calibrates the CUSUM reference value and decision limit by optimizing a trade-off between sensitivity proxies and false-alarm penalties using a finite sample of normal scores, without anomaly labels or a user-specified target alarm rate. We evaluate the method across different scoring models and datasets, comparing it with alternative decision rules using observation-level detection metrics, false-alarm episode counts, and detection delay.
